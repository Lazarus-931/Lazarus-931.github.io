Introduction: Section: Narrowing the playing field In deep learning, chipping away at problems, simplifying them to their core essence, is a delicate effort. On one had, the definition we hold for these models can be over-shot preventing any progress, or too simple for any progress. One aspect that *does* help, is starting top-to-bottom approach, starting with representing the model. We have here a model $M$, now $M(x, \theta)$ is a function that takes input $x$ with parameters $\theta$. In the most basic form, the concept of a model, is one which can act on data, or otherwise return something given an input. For simplicity, we can think of a linear model, where $M(x)_t = \sigma(W x)$, where $\sigma$ is an activation such as ReLU. Now taking a simple MLP, we can write as such layers of linear transformations, where each matrice is learned through training, through a simple equation called MSE: $$\mathcal{L} = \frac{1}{N} \sum_{i=1}^N (y_i - M(x_i)^2)$$ Seems as if, we have a model, a loss and a training procedure. Where for example a model can be: $$M(x) = \text{GELU}(x) = x * \Phi(x)$$ [C1] Assessing differnet model parameter sizes with respect to the same MNSIT, we see there is a interpolation regime[Belkin et al.
